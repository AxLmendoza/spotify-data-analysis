# spotify-data-analysis
Una empresa de música quiere entender qué características hacen que una canción sea popular. Mi trabajo como analista es explorar los datos, encontrar patrones y presentar conclusiones que ayuden a tomar decisiones.

## 📌 Descripción

Este proyecto realiza un análisis exploratorio de un conjunto de datos de Spotify utilizando Pandas.

El objetivo es responder preguntas de negocio relacionadas con la popularidad, duración y distribución de las canciones.

---

## 🛠 Tecnologías

- Python
- Pandas
- Google Colab

---

## 📊 Preguntas respondidas

- ¿Cuáles son los 10 géneros con más canciones?
- ¿Cuáles son las 10 canciones más populares?
- ¿Cuál es la popularidad promedio por género?
- ¿Cuál es el género con mayor popularidad promedio?
- ¿Cuál es el género con menor popularidad promedio?
- ¿Cuál es la duración promedio por género?

Spotify Tracks Dataset (Kaggle)
